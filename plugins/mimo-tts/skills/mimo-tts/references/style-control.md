# MiMo TTS 风格控制

## 选择控制方式

| 目标 | 写在哪里 | 示例 |
| --- | --- | --- |
| 描述整段如何演绎，或交代情绪转场与重音 | `--instruction`，API 的 `user` 消息 | `第一句用播报口吻，第二句降到低语。在「还有三分钟」上加重音。` |
| 给整段添加简短风格 | 正文最开头，API 的 `assistant` 消息 | `（温柔 平静）今天就先聊到这里。` |
| 在特定位置加入声音或切换语气 | 正文中相应位置，API 的 `assistant` 消息 | `门终于开了。[松一口气] 我们赶上了。` |

自然语言指导可覆盖段落基调、句子节奏、词语重音，或某个字的气声和拖音。用可听见的特征表达需求，例如「一句内先平静后上扬」「语速稍快但尾句放慢」「说『天亮』时带着一点哽咽」。方言可以直接写进指导，也可以在正文开头使用 `（粤语）`、`（四川话）` 等风格标签。指导与标签搭配时，为同一位置提供一致的演绎要求。

## 自然语言与导演指导

给简单需求写一句话即可。例如「用温柔但略显疲惫的语气，整体偏慢，读到『终于到了』时短暂停顿，再用轻微笑意收尾」。需要较细的角色表演时，将三方面写在同一段 `--instruction` 中。

```text
【角色】一位作风稳重的博物馆讲解员，普通话清晰，习惯以平静语气讲述意外发现。
【场景】闭馆前，向最后一位观众介绍刚修复的手稿。
【指导】开头像平常讲解，节奏均匀。说到「背面」时停顿半拍，随后压低音量，带一点克制的兴奋。重读「签名」。
```

这段指导可搭配正文 `这张纸的背面，还有一行从未公开过的签名。`。演绎指导由 `user` 消息传送，朗读的台词由 `assistant` 消息传送。

## 整体风格与句中音频标签

- 篇首标签可用 `(风格)`、`（风格）` 或 `[风格]`。把多个风格放在同一对括号中，如 `（温柔 醇厚）`。常见的描述包括平静、干练、俏皮、磁性、清亮以及方言。也可使用具体的自定义描述。
- 句中标签放在效果发生的位置，如 `[深呼吸]`、`[停顿]`、`[轻笑]`、`[低声]`、`[咳嗽]` 和 `[语速加快]`。官方例子也使用圆括号，例如 `我以为已经关灯了。（压低声音）你看，楼上还有一扇窗亮着。`
- 原稿需要逐字保留时优先用 `--instruction`，可在指导中引用原文定位重音和节奏。原稿已带标签时沿用原有位置。试音后如需微调，优先调整关键段落的语速、情绪或标签。
- 唱歌使用 `preset`，并把 `(唱歌)` 放在整个正文的最开头，后接歌词。`(sing)` 和 `(singing)` 等效，官方建议优先试中文歌词。示例 `（唱歌）金色的风吹过小路，归家的灯在前面亮起。`

## 音色选择与参考录音

**预置音色**可用 `mimo_default`，或直接选择中文音色 `冰糖`、`茉莉`、`苏打`、`白桦`，英文音色 `Mia`、`Chloe`、`Milo`、`Dean`。`mimo_default` 的实际音色取决于服务集群。

**设计音色**用一到四句话说明最重要的声线特征，可包括年龄感、音域、质感、口音、咬字与语速，再加一条场景或演绎指导。例如「一位年长的女性，声音偏低且温厚，带轻微北方口音，字头清楚、尾音放松。像给孙辈讲故事，语速平缓，句尾留短停顿。」混响、EQ 等后期效果适合在音频生成后处理。

**复刻音色**使用干净、清晰的单人录音。优先选自然说话、语速稳定、背景音乐和混响较少的片段。脚本按 WAV 或 MP3 读取本地样本并发送给 MiMo。样本决定要复刻的音色，`--instruction` 继续用于控制新台词的演绎。
